# SHODA - Online Shoe Shopping Website

## Project Overview

SHODA is a dynamic shoe shopping web application built using HTML, CSS, and JavaScript.

The website allows users to browse different shoes, select available sizes, add products to a shopping cart, manage quantities, and save their cart data using browser local storage.

## Features

### Dynamic Product Display

- Product information is stored in a JSON file.
- JavaScript fetches product data and creates product cards dynamically.
- Products can be updated by modifying only the JSON file.

### Search Functionality

- Users can search shoes by product name or brand.
- The displayed products update based on the search input.

### Shopping Cart

Users can:

- Add shoes to cart
- Select shoe sizes
- Increase product quantity
- Decrease product quantity
- Remove products
- View total price

### Local Storage

The application uses browser localStorage to save cart information.

This allows users to:

- Refresh the page without losing their cart
- Continue shopping from where they stopped

## Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript ES6

## JavaScript Concepts Used

### Fetch API

Used to load product information from products.json.

### DOM Manipulation

Used to create and update HTML elements dynamically.

### Event Listeners

Used to handle user actions:

- Button clicks
- Size selection
- Cart operations
- Search input

### Array Methods

Used methods:

- forEach()
- find()
- push()
- splice()

### Local Storage

Used to store cart data permanently in the browser.
